# 경진대회 영상·발표 시나리오 (약 3~4분)

> 촬영 환경: PC Chrome 으로 Flutter Web 실행(화면 가운데 휴대폰 프레임으로 표시) 또는 휴대폰 브라우저.
> 시작 전: 설정 > 앱 버전 5번 탭 → 데모 모드 → ADMIN_KEY 연결 → "데모 알림 모두 삭제".

## 0. 문제 제기 (20초, 슬라이드)

- 국내 체류외국인 273만 명(2025.6 말) — 중국·베트남·미국·태국·우즈베키스탄 순 ([헤럴드경제](https://www.heraldk.com/article/2025072621211091744))
- 재난문자 본문은 한국어. 2024년부터 위급·긴급 문자에 재난유형 영문 병기만 추가 ([파이낸셜뉴스 2024-02-28](https://www.fnnews.com/news/202402281202462834))
- 정부 앱(Emergency Ready App)은 2026.6 개편으로 22개 언어 재난문자·대피소 지도를 제공 ([뉴시스](https://www.newsis.com/view/NISX20260614_0003668232))
- ResQ 는 여기에 **위급 상황에서 외국인이 한국어로 도움을 요청하는 기능**(119 신고 도우미, 구조대원용 한국어 응급정보 QR)을 더함
  ※ 발표 전 정부 앱 최신 버전을 직접 설치해 같은 기능이 없는지 확인하고, "공식 발표 자료 기준"이라고 말할 것

## 1. 첫 실행 (20초)

언어 선택 화면에서 **Tiếng Việt** 선택 → 홈이 베트남어로 바뀜 → 설정에서 "내 위치로 자동 설정" → 지역이 천안으로.

## 2. 재난 알림 수신 → 이해 → 행동 (60초) ★핵심

1. 데모 모드에서 **earthquake** 전송 → 뒤로 → 상단에 빨간 **새 긴급 알림 배너**(베트남어) + 음성 안내
2. 배너 탭 → 알림 상세: 베트남어 번역, **한국어 원문 보기** 토글(공공데이터 원문 제공), "소리내어 읽기"
3. "지금 해야 할 일" — 지진 행동요령 5단계
4. **가까운 대피소 찾기** → 지도에 대피소 표시 → 길찾기

## 3. 신고 도우미 (40초) ★차별점

홈 > 긴급 문장 → 내 위치가 **한국어 주소**로 표시 → ▶ 재생("제 위치는 다음과 같아요: …") → "불이 났어요" 카드 재생 → 119 버튼.

## 4. 응급정보 QR (40초) ★차별점

My Info → 이름·혈액형·알레르기(베트남어로 "Đậu phộng")·연락처 입력 → 저장 → **QR 코드** 표시 → "구조대원 화면 미리보기" → 한국어로 번역된 응급정보(괄호 안 원문), 1345 통역 안내, 연락처 전화 버튼.

## 5. 대사관 (15초)

대사관 탭 → "Viet" 검색 → 전화·지도·이메일.

## 6. 기술 (30초, 슬라이드)

- 구조: Flutter Web ↔ Node.js/Express ↔ MySQL, 공공데이터(재난문자·민방위 대피시설) 5분 주기 수집, Google Cloud Translation 서버 번역 + DB 캐시, OpenStreetMap
- 신뢰성: 재난문자 일련번호(SN) 중복 제거, 공식 긴급단계(위급·긴급·안전안내) 기반 심각도, 다지역 매핑
- 보안·비용: 기기 인증으로 타인 의료정보 조회 차단, 관리자 키, 요청 제한, 일일 번역 상한(무료 크레딧 내)
- 품질: 백엔드 자동 테스트 27개 통과, 원본 대비 결함 27건 수정 (docs/ANALYSIS.md)
